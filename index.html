Projetos

Detector de Erros Conceituais (MC3)

É uma ferramenta em Python voltada para apoio pedagógico na disciplina de Introdução à Programação. O sistema é uma adaptação que realiza a análise estática automatizada em códigos enviados via Moodle para identificar e quantificar Misconceptions in Correct Code (MC3), que são erros de lógica ou estrutura em códigos que compilam, mas violam boas práticas conceituais.

O que eu fiz:

  • Motor de Detecção: Adaptei e estruturei a classe VisitorMC3 para varrer submissões de código sem depender de erros de sintaxe. A classe foi extraída e adaptada do repositório original.
  • Validação Inteligente: Integrei a biblioteca pyspellchecker para verificar nomenclaturas de variáveis, eliminando falsos positivos em constantes válidas e nomes curtos.
  • Geração de Métricas: Desenvolvi rotinas em Python para processar dados em JSON e exportar relatórios detalhados (.txt) e planilhas de desempenho (.csv) com o ranking dos erros mais comuns.

Tecnologias:

Python - Análise Estática - Parsing (JSON/CSV)
